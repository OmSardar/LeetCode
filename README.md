# LeetCode Solutions

A personal collection of LeetCode solutions, organized by difficulty and problem-solving topic. The solutions are primarily written in Java.

## Repository Structure

```text
LeetCode/
├── 1.EASY/
├── 2.MEDIUM/
└── 3.HARD/
```

Each difficulty folder contains topic folders such as **Arrays**, **Strings**, **Hashing**, **Linked List**, **Trees**, **Graph**, and **Dynamic Programming**. Inside a topic folder, each problem has its own folder named after the problem. When the same problem fits multiple topics, it may appear in more than one topic folder.

## Solution Files

Java source files (`.java`) contain the solutions. Some problem folders also include compiled Java class files (`.class`). The source files are intended to be viewed or submitted using the format required by LeetCode; helper classes and method signatures may follow LeetCode's conventions.

## Browse the Solutions

Choose a difficulty, open a topic, then open a problem folder. For example:

```text
1.EASY/1.ARRAYS/TwoSum/
```

## Disclaimer

These solutions are for personal learning and reference. There may be multiple valid approaches to a problem, and solutions may be refined over time.
